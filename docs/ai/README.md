# Навигация для ИИ-агентов — как это устроено

Цель: агент читает не всю кодовую базу (~400 тыс. строк), а только нужный участок.
Аналогия — библиотека: агент не помнит все книги, у него есть **каталог** и **таблички на стеллажах**.

## Три уровня

| Уровень | Файл | Когда читается | Что внутри |
|---|---|---|---|
| 1. Вход | `CLAUDE.md` (корень) + `AGENTS.md` | Всегда, при старте сессии | Что за проект, жёсткие правила, как пользоваться картой, протокол обновления |
| 2. Каталог | `docs/ai/MAP.md` | По запросу, в начале задачи | Таблица «задача → папка → входной файл», индекс папок, список больших файлов |
| 3. Таблички | `CLAUDE.md` внутри папок подсистем | **Автоматически**, когда агент открывает файл в этой папке | Паттерны, правила и подводные камни конкретной подсистемы |

Почему это экономит контекст: уровень 1 — около 60 строк; уровень 2 читается один раз за задачу;
уровень 3 подгружается только для той подсистемы, которую трогают. Claude Code подхватывает вложенные
`CLAUDE.md` сам; другие агенты (Codex, Cursor и т.п.) читают `AGENTS.md`, который направляет туда же.

Агентские файлы написаны по-английски намеренно: так они короче в токенах и совпадают с именами в коде.

## Правила обновления (кратко; полная версия — в корневом `CLAUDE.md`)

- Изменилась структура (новая/переименованная папка, новая подсистема, другой входной файл) → `MAP.md`.
- Изменилось правило или паттерн внутри папки → `CLAUDE.md` этой папки.
- Появилась папка на ~10+ файлов или со своими правилами → новый `CLAUDE.md` по шаблону ниже + `.meta` + строка в `MAP.md`.
- Писать **где и почему**, не копировать код и не указывать номера строк — они устаревают первыми.
- Проверка: `python3 docs/ai/check_docs.py` (несуществующие пути, отсутствующие `.meta`, папки с `CLAUDE.md`, которых нет в карте).

## Шаблон `CLAUDE.md` для папки

```
# <Папка> — <одна строка: за что отвечает>

<2–3 строки: главные классы и как они связаны.>

## Key files
- `File.cs` — роль.

## How to <типовая задача>
1. ...

## Rules
- Инварианты, которые легко сломать (сеть, сохранения, публичный API для плагинов).

## Pitfalls
- Неочевидное, на что уже тратили время.
```

Файл в `Assets/` должен иметь `.meta` (иначе Unity создаст его сам и появится лишний diff).
Формат — как у `Assets/Runtime/UnityEx/README.md.meta`, с новым GUID:
`python3 -c "import uuid;print(uuid.uuid4().hex)"`.

## Что ещё можно добавить (не сделано)

- Запуск `check_docs.py` в CI (GitHub Actions) — чтобы устаревшая карта ломала сборку.
- Хук Claude Code `Stop`/`PostToolUse`, напоминающий обновить `CLAUDE.md`, если менялись `.cs` в папке с ним.
- Таблички для остальных папок (`Framework/Devkit`, `Unturned/Level` подробнее, `Glazier*`) — по мере работы с ними.
