# NetInvokable — RPC system

Runtime for remote calls between server and clients. Serialization code is generated into `NetGen/`.

## Pattern (copy from a neighbour, e.g. `Unturned/Player/PlayerLife.cs`)

```
private static readonly ClientInstanceMethod<byte> SendHealth =
	ClientInstanceMethod<byte>.Get(typeof(PlayerLife), nameof(ReceiveHealth));
[SteamCall(ESteamCallValidation.ONLY_FROM_SERVER, legacyName = nameof(tellHealth))]
public void ReceiveHealth(byte newHealth) { ... }
// server side:
SendHealth.Invoke(GetNetId(), ENetReliability.Reliable, channel.GetOwnerTransportConnection(), health);
```

- `Client*Method` = server → client. `Server*Method` = client → server (a request; validate everything).
- `*InstanceMethod` targets an object by `NetId`; `*StaticMethod` targets a static method.
- `[SteamCall]` validation (enum in `Unturned/Provider/SteamChannel.cs`): `ONLY_FROM_SERVER` for
  client receivers; `ONLY_FROM_OWNER` / `SERVERSIDE` for server receivers. Use `ratelimitHz` on any
  client → server request that a cheater could spam.
- A server receiver may take `in ServerInvocationContext context` as first parameter:
  `context.GetPlayer()`, `context.GetCallingPlayer()`, `context.Kick(reason)`.
- Recipients: `channel.GetOwnerTransportConnection()`, `channel.GatherRemoteClientConnectionsExcludingOwner()`,
  `Provider.GatherRemoteClientConnections()`, `...WithinSphere(...)` variants in `Provider.cs`.
- `InvokeAndLoopback` also runs the receiver locally (listen server / singleplayer).
- Parameter compression is controlled by attributes in `NetInvokableAttributes.cs`
  (`[NetPakVector3]`, `[NetPakNormal]`, ...).

## Rules

- **After adding, removing or changing the signature of a `[SteamCall]` method, regenerate** in Unity:
  menu *Window → Unturned → Net Gen → Generate*. This rewrites `NetGen/NetInvokable/*_NetMethods.cs`.
  Without Unity: say in the report that NetGen must be regenerated; do not hand-write generated files.
  A missing generated method logs "Unable to find ... receive implementation" at startup and the RPC is dead.
- The RPC index table depends on the set of methods → client and server must run the same build.
- Keep `legacyName` when renaming a receiver — plugins call RPCs by the old name.
- New network enums: generated by `Assets/Editor/Assembly-CSharp-Editor/NetGen/NetEnumGenerator.cs` into `NetGen/NetEnum`.
